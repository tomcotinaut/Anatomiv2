# AnatoQuiz – GitHub Pages

Application web statique, mobile-first, en français.

## Publication depuis iPhone
1. Crée un dépôt GitHub public nommé `anatoquiz`.
2. Dans le dépôt, appuie sur **Add file → Upload files** et ajoute `index.html`.
3. Va dans **Settings → Pages**.
4. Sous **Build and deployment**, sélectionne **Deploy from a branch**, branche `main`, dossier `/root`, puis **Save**.
5. Après quelques minutes, ouvre `https://TON-NOM.github.io/anatoquiz/`.

Le site est statique et fonctionne sans serveur. Les préférences de rappel sont conservées localement dans le navigateur. Les notifications en arrière-plan nécessitent une installation PWA et une configuration spécifique; ce prototype ne prétend pas envoyer des notifications lorsque Safari est fermé.

## Contenu
Le prototype inclut des quiz d'exemple par région (tête/cou, membre supérieur, tronc, bassin, membre inférieur, pied/cheville), thèmes, QCM avec correction immédiate et localisation interactive. Les illustrations sont pédagogiques et schématiques, pas des planches d'atlas ni des modèles anatomiques diagnostiques. La banque devra être enrichie et vérifiée région par région pour une couverture exhaustive.
